# Portfolio Mbewe

Portfolio React avec Vite, en français et adapté aux écrans mobiles.

## Développement

Prérequis : Node.js 22.12+ (ou 20.19+) et npm.

```sh
npm ci
npm run dev
```

## Production

```sh
npm run build
npm run preview
```

Le site compilé se trouve dans `dist/`.

## Personnalisation

Modifiez `profile`, `skills` et `projects` dans `src/App.jsx`.
Les textes entre crochets sont des exemples à remplacer. Ajoutez votre adresse
dans `profile.email` pour afficher le bouton e-mail, et les liens de vos projets
dans leur champ `url`. Les styles sont dans `src/styles.css`.
